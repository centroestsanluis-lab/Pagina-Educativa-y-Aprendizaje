# Guía para instalar CESL Digital en las 20 tablets

Tablets: Android 11, 3 GB de RAM, 32 GB, con internet. Tiempo: unos 3 minutos por tablet.

## Antes de empezar (una vez por tablet)
1. **Ajustes → Sistema → Actualización**: instale las actualizaciones pendientes.
2. **Play Store**: actualice **Google Chrome**.
3. Conecte la tablet al Wi-Fi del colegio.

## Instalar la aplicación
1. Abra **Chrome** y escriba: `colegiosanluis-gt.github.io/Pagina-Educativa`
2. Espere a que aparezca LU y el botón **Comenzar**.
3. Toque el menú **⋮** (arriba a la derecha) → **Instalar aplicación** (o **Agregar a la pantalla principal** → **Instalar**).
4. Aparecerá el ícono de **LU** en la pantalla de inicio. Desde ahora abra siempre CESL Digital con ese ícono: se abre a pantalla completa, sin barra de direcciones.
5. Ábralo y compruebe que aparece la bienvenida.

## Ajustes recomendados para tablets compartidas
1. **No guardar contraseñas**: Chrome → ⋮ → Configuración → **Administrador de contraseñas** → desactive "Ofrecer guardar contraseñas" e "Inicio de sesión automático". Así un alumno no entra con la cuenta de otro.
2. **Fijar la aplicación** (evita que los niños salgan a otras apps o a internet): Ajustes → Seguridad → **Fijación de pantalla / Fijar app** → activar. Abra CESL Digital → botón de apps recientes → toque el ícono de la app → **Fijar**. Para soltar: mantenga presionados *Atrás* y *Recientes* (el procedimiento exacto varía según la marca).
3. Brillo automático y **suspensión de pantalla en 5 minutos** para ahorrar batería.
4. Coloque una etiqueta con un número (Tablet 01 a 20) para el control de inventario.

## Uso diario
- Cada alumno entra con **su** usuario y PIN y, al terminar, toca **⚙️ → Cerrar sesión**.
- Si alguien olvida cerrar sesión, la plataforma la cierra sola tras **30 minutos** sin uso.
- Las actualizaciones de la plataforma llegan solas: no hay que reinstalar nada.

## Si algo falla
| Problema | Solución |
|---|---|
| No carga / "No hay conexión" | Revise el Wi-Fi y vuelva a abrir |
| Se ve una versión vieja | Cierre la app desde Recientes y ábrala de nuevo |
| No aparece "Instalar aplicación" | Actualice Chrome; use "Agregar a la pantalla principal" |
| Un PDF no se abre | Pida al docente que verifique que el archivo de Drive esté compartido como "Cualquier persona con el enlace" |
| Va lenta | Cierre las demás apps; reinicie la tablet una vez por semana |
